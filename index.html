A little number magic

A number with a destination.

Kaprekar's routine is a simple process of sorting digits and subtracting. Repeat it a few times, and your number reaches the same special constant.

Try the routine →

The process

Three steps. Repeat until it settles.

  1. 01

    Choose a number

    Start with any 3- or 4-digit number whose digits aren't all identical.

  2. 02

    Arrange and subtract

    Order its digits from largest to smallest, then smallest to largest. Subtract the smaller number from the larger.

  3. 03

    Repeat

    Use the answer as your next number. Keep leading zeroes so every number has the same number of digits.
